# 司忆 v17.0.1

Windows 桌面补丁版本。

- 无工作区对话在首次模型请求之前写入受任务租约保护的检查点。首次请求超时或中断后，可以显式继续同一个任务；不自动重试，也不重复保存用户消息。
- 个人／项目记忆按当前命名空间和工作区显示。切换范围时不再短暂显示上一范围的记录；已过期的读取请求不会覆盖新范围。

新的检查点仅适用于本补丁启动的任务；不会为旧版已失败且缺少检查点的任务补造记录。

不修改 SQLite Schema、历史会话、记忆范围、权限规则或 Windows 凭据归属。升级继续使用原数据目录，验证须使用独立合成数据。麦克风和付费云模型不在本补丁验证范围内。

[当前验收状态](RELEASE_STATUS.json)单独维护；这份说明不表示已经打包、发布或安装。
