# 司忆 v9.4.0 本地发布说明

- 工具映射到 13 类规范权限，保留旧会话授权兼容。
- 支持单次、任务、工作区、始终允许与拒绝；拒绝优先，持久策略可查看和撤销。
- critical 操作不能使用持久允许策略，管理员域也不能绕过。
- 增加普通、开发者、管理员安全域；管理类 Skill 默认不向普通域暴露。
- Skill 安装先进入隔离区，完成严格 Manifest 与第三方脚本静态扫描后才激活。
- 运行时禁止 `npm/pip` 等自动安装，命令必须命中允许列表并继续经过危险命令识别、确认和安全快照。
- 网络请求继续受域名白名单、SSRF、重定向、响应大小与凭据跨域保护。
- Windows Credential Manager 的密钥名称和大小受限；后端契约只接受 `secret://name` 不透明引用。
- 设置界面可查看安全域、允许列表和持久授权，并显式切换安全域或撤销授权。
