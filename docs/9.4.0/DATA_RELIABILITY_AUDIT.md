# v9.4.0 权限与密钥数据可靠性审计

结论：`PASS`。

- 持久策略明确记录权限、效果、范围、工作区、工具、来源、主体、创建与撤销时间。
- deny 优先于 allow；工作区授权不能跨工作区复用；critical 不接受持久 allow。
- 明文确认令牌只存 SHA-256，单次令牌不可重放，任务授权随任务结束清理。
- Secret 值不进入权限表、API 状态、日志或诊断；审计详情继续经过统一脱敏。
- Skill 隔离校验失败不创建活动 Skill；升级前归档旧版本，激活失败可从归档恢复。
- 普通安全域隐藏受保护开发 Skill，域切换和策略修改要求显式管理员确认并记录审计。
