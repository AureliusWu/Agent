# 司忆 v8.0.1

v8.0.1 是能力强化、真实桌面验证和上下文成本治理版本。

## 主要变化

- Windows 桌面目录架构收敛，前端、后端与测试按领域组织。
- 恢复夏目心中央头像和右侧角色头像。
- Runtime 队列、STEER、STOP、检查点、恢复、Verifier 与操作幂等能力强化。
- 上下文固定前缀、类型化任务状态和重复文件内容哈希引用。
- DeepSeek/OpenAI 缓存 Token、未缓存 Token、阶段用量和价格快照账本。
- 用量页展示缓存命中率和 Token 构成。
- SQLite Schema v29。
- EvoPolicyGym 固定官方 commit，Toy 与 CartPole 已真实运行。
- 真实场景 Evidence Schema、隔离 AppData 与 Windows Computer Use 基础设施。

## 发布说明

本版本由管理员于 2026-07-26 明确要求发布。未完成的 24 小时耐久、部分真实场景、MSI 管理员生命周期和 Evo 二次反馈测试作为已知警告保留，不得解释为 PASS。

云端升级测试以正式发布的 v7.0.0 为基线。
