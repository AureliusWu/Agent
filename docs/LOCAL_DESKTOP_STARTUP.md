# 本地 Windows 桌面启动契约

## 默认入口

日常双击使用根目录 `启动司忆.vbs`。桌面快捷方式应指向 Windows Script Host 的 `wscript.exe`，参数为此 VBS 的完整路径，工作目录为应用根目录。

VBS 通过相对于自身的路径找到 `scripts/start-local-desktop.ps1`，使用 Windows PowerShell 5.1 的隐藏、非交互、无 Profile 模式，并等待其完成启动校验。它不再经过 CMD/Windows Terminal，所以正常启动不会先打开终端。VBS 源码保持 ASCII；中文与含空格的安装路径由 Windows Unicode API 提供，不在源码中嵌入本机绝对路径。

隐藏的是启动控制台，不是安全校验：完整运行时 SHA-256 与文件数量、内嵌构建身份、数据所有权、路径链接保护、已有进程与创建时间、单实例互斥检查保持不变。不会关闭已有应用或绕过异常。

## 失败与诊断

启动脚本失败或缺失时，VBS 显示失败对话框及诊断入口，不静默退出。需要详细原始错误时，在已经打开的终端中运行根目录 `启动司忆.cmd`。CMD 保留相同 PowerShell 校验脚本，不自动 `pause`，也不另开终端。

显式通过 `cscript.exe //NoLogo 启动司忆.vbs` 调试时，错误写到控制台并返回非零退出码，不弹出会阻塞自动化的对话框。不要将 `cscript.exe` 作为日常桌面快捷方式。

## v16 补丁升级与数据连续性

`scripts/activate-local-desktop.ps1` 仅接受与根目录 `VERSION` 完全一致、具有真实内嵌构建身份的 v16.x 运行时。替换前原样归档旧激活清单，重新生成全部运行时文件大小与 SHA-256；激活不启动应用、不执行模型调用，也不宣称正式发布验收。

v16.0.1 等补丁更新更改运行时 `product_version`，但沿用原始数据所有者 `siyi-user-testing-v16.0.0`，默认数据目录仍为应用相邻的 `司忆数据/v16.0.0`。这不是版本号遗漏，不进行迁移、不重建数据库，也不更改已有会话或密钥。其他所有者、非 v16 激活清单、未知清单 Schema 均拒绝替换。

## 回归证据边界

`test_quiet_desktop_launcher.py` 在中文含空格临时目录中，复制 VBS 并执行自有无害 PowerShell stub，验证隐藏参数、无主窗口句柄、工作目录与成功/失败退出码；不会启动真实司忆或读取凭据。激活测试使用不可执行的合成 EXE 字节，覆盖同版本重激活、v16.0.0 → v16.0.1 所有者保留以及外来所有者/版本族/Schema 拒绝。

这些测试不代替已打包程序的真实桌面可见性检查、安装验收或模型验收。
