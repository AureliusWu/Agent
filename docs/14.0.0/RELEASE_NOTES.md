# 司忆 v14.0.0 本地发布说明

v14.0.0 聚焦 Windows PC 端的本地语音闭环：麦克风录音经本地 Faster-Whisper 转写为可编辑的普通用户消息，继续走司忆既有的权限、危险操作确认、任务执行、验证和停止链路；回复可由稳定的 Windows 系统 TTS 朗读。MeloTTS 保留兼容接口，但明确标为实验性能力，不作为正式发布阻断项。

本版本增加本地 STT 模型的确认下载、加载、卸载、取消和资源状态管理。新安装推荐使用 `small` 多语言模型、CPU 与 `int8`；已有用户保存的模型选择不会被升级覆盖，应用启动时也不会自动加载或隐式下载模型。Ollama 的 External 与 Managed 生命周期继续区分，测试或应用托管的进程必须绑定所有权和进程身份，外部进程受到保护。

语音输入支持点击开始/结束和按住说话，录音、STT、Agent、TTS 具有可恢复的 Voice Session 事件；松开、取消、全局停止、窗口隐藏或连接失效会收敛并释放本地资源。音频和转写原文默认不进入普通日志，临时 WAV、诊断包和模型路径按受控目录与脱敏规则处理。

本地发布是否完成，以同目录生成的 `RELEASE_STATUS.json`、`TEST_MATRIX.json`、`EVIDENCE_MANIFEST.json` 和 `IMPLEMENTATION_FEEDBACK.md` 为准。开发态、合成音频、Mock 或接口存在均不替代正式安装包、真实麦克风、30 分钟耐久、NSIS 与管理员 MSI 的实际验收证据。
