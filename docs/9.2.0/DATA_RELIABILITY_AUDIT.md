# v9.2.0 文件数据可靠性审计

结论：`PASS`。

- 所有路径先解析为工作区内规范化绝对路径；UNC、设备路径、盘符相对路径、目录穿越、软链接和 Junction 越界被拒绝。
- 覆盖、移动、删除和目录删除均在 `.agent-backups` 生成带 before/after 状态的持久事务清单。
- 写入使用同目录临时文件、fsync 和原子替换；失败时恢复原文件。
- 文件版本 Token 防止读取后被外部修改却继续覆盖。
- UTF-8、UTF-8 BOM、UTF-16 和 GB18030 显式记录；二进制与超大文件不会被静默当文本写回。
- dry-run 不创建目标或备份；批量失败只回滚本批已经完成的 change_id。
- I/O 错误保留异常类型、errno、winerror、文件名与 retryable，不用空成功替代失败。
