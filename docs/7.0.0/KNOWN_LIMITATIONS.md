# 7.0.0 已知限制

1. 30 分钟至 72 小时耐久矩阵尚未在当前候选提交完成；目前只有单轮规定规模压力和运行器冒烟证据。
2. Windows 真实休眠/唤醒、工作区 ACL 动态变化和 WebView 长断线需要人工环境验收。
3. 旧 Multi-Agent 与 Professional Agent Eval 文件仍作为历史兼容资产存在；产品已明确统一为单一通用 Agent，不能为了旧 Eval 重新启用已移除的公开路径。
4. 7.0.0 仍使用单一 SQLite 数据库；这是降低迁移与事务风险的明确设计，不代表已完成 `siyi.db`/`kokoro.db` 拆分。
5. AppData 隔离不等同于全库磁盘加密；密钥使用系统凭据边界，数据库全库加密留待后续评估。
6. 当前版本仍为 6.0.0；只有发布候选全部门禁通过后才能统一升级版本元数据。
