# 司忆 v9.0.1 发布说明

v9.0.1 把本机 Ollama 从“可以接入”收敛为日常可用：固定使用 `qwen3:4b`，自动识别 Ollama 版本与已安装模型，提供首次加载提示、可配置失败重试和清晰的环境错误，不会自动下载模型，也不会回退到付费 Provider。

## 主要变化

- 模型设置在选择 Ollama 时自动执行真实诊断，显示 Ollama 版本、服务状态、模型大小与更新时间。
- 修复未保存切换状态错误沿用 DeepSeek 诊断的问题；诊断现在绑定界面当前选择，保存后会再次检查。
- 对“服务未启动、模型未安装、11434 端口被其他服务占用、响应无效”提供可执行提示。
- `qwen3:4b` 输出预算下限为 2048 Token，旧的低预算配置只在内存中安全归一化，不暗改用户文件。
- 新增 0–5 次失败重试配置，默认 2 次。
- 模型运行记录新增可空的 `first_token_ms`；数据库 Schema 从 32 升至 33，并在迁移前自动备份。
- 前端 API Key 输入只在 DeepSeek 模式出现；Ollama 不需要也不会接触 DeepSeek Key。

## 验证结论

- 后端全量回归：`461 passed, 7 skipped`，覆盖率 `82.67%`。
- 真实 Ollama：`5/5 PASS`，包含 10 轮对话、10 次流式、10 次多轮工具调用和中途取消。
- Core Eval：`18/18 PASS`；Rust：`5/5 PASS`。
- 桌面成品、安装包、Schema 迁移、卸载保留与重装识别均通过隔离烟测。
- DeepSeek 付费测试按用户节省 Token 的要求保留为 `NOT_RUN`；付费调用次数为 0。
- 24 小时耐久按用户明确要求标记 `NOT_APPLICABLE`。

本版本为 `READY / LOCAL_ONLY`，未推送 GitHub。
