严重程度：LOCAL-01/03 为 P1，LOCAL-02/04 为 P2。没有据此认定真实密钥已泄露到第三方；LOCAL-03 原路径只发送到已认证本地 Sidecar，但仍是不必要的敏感读取。

## 基线实机已确认

- 隔离 Mock 配置正常启动，没有可见控制台窗口。
- Mock 明确不支持推理强度时，滑条确实禁用并显示真实限制；这是 PASS，不是新增缺陷。真实 `/api/provider/policy` 路由契约已有回归保护。
- 模型与 API 页面能够载入 Mock 配置，“检查连接”显示获取 1 个模型并明确未执行付费对话。
- 正常关闭测试实例，Sidecar 退出，不强杀进程。

## 安全与测试边界

使用仓库外全新隔离 profile、合成工作区和 Mock Provider。保留真实数据库、模型、凭据、旧完整运行时和快捷方式；不升级依赖或修改 Windows 安全设置。GUI 的破坏性删除、真实凭据改动、麦克风权限和付费服务验证不自动执行；其代码分支可由隔离回归覆盖，但不能标为真实 GUI/真实服务通过。

初次代码修复、测试和构建后，最终实机结果与编译身份写入 `IMPLEMENTATION_FEEDBACK.md`，私有原始记录保存在仓库外本次自动测试目录。旧失败和旧构建证据不覆盖。
