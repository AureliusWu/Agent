# 司忆 v16.0.1

Windows PC 本地用户测试更新，不是完整正式发行。

## 本次调整

- 默认启动入口改为 `启动司忆.vbs`，隐藏命令行窗口；校验或启动失败仍显示错误提示。`启动司忆.cmd` 保留作诊断入口。
- 模型菜单中的推理强度改为可拖动、可用键盘操作的四档滑条：自动、低、中、高。沿用现有 Provider 参数，不新增 Ultra 等未经支持的档位。
- 右上角增加工作台开关；右侧支持工作区文件、只读文件标签、会话状态及夏目心面板。文件读取继续经过原工作区、权限和审计接口。
- 同步 Python、npm、Cargo、Tauri 和运行时版本为 16.0.1。

## 数据和边界

继续使用 `../司忆数据/v16.0.0` 和原有数据所有者，不新建空白 v16.0.1 数据库，不迁移或重置聊天、模型、密钥。没有数据库迁移、依赖升级或新的付费验证。

本地更新保留上一运行制品及快捷方式的可恢复备份。实际构建身份及验证结果见 `IMPLEMENTATION_FEEDBACK.md`。历史 v16.0.0 标签与失败记录不改写；原先跳过的正式安装、真实模型及人工验收不因本补丁变成通过。本次不接入联网自动更新服务。
