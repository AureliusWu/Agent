## 审计边界

右侧工作台只读调用 `/api/tools/execute` 的 `list_files/read_file`，带会话、工作区和权限；后端再次核对会话归属。最多 8 个文本标签，2 MB / 40,000 字符，内容作为纯文本呈现。会话/工作区/权限变更重置独立作用域，目录和文件请求均有晚响应隔离。

另标记主 App 原有权限保存的异步竞争：权限保存尚未返回时切换会话，旧响应可能将主 App 选中项切回。不是本补丁引入，本轮未修改此旁支；新工作台自身不会将旧文件响应写入新作用域。
