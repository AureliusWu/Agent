# 司忆 v9.6.0 视觉与多模态实施计划

## 目标

把视觉能力放入 Agent Core，提供供应商中立的 `vision.describe`、`vision.extract_text`、`vision.analyze_chart`、`vision.compare`、`vision.inspect_ui`、`vision.classify` 接口。远程视觉模型可接入，本地视觉模型保留同一协议；无视觉能力时明确降级，不把 OCR 后备结果伪装成模型视觉结论。

## 安全与隐私边界

- `skills.zip` 仅作行为参考，不安装、不执行、不复制其实现。
- 禁止源码、Skill、Manifest 和默认配置包含 API Key；密钥只能来自请求级凭据或现有 Secret 引用。
- 图片限定工作区或显式上传暂存区，校验 MIME、签名、尺寸、像素数、帧数和总字节数。
- 发送给远程 Provider 前统一重新编码，清除 EXIF、GPS、ICC、文本块及其他元数据。
- 审计只记录哈希、尺寸、MIME、处理动作和供应商，不记录图片字节、base64 或识别全文。
- 多图数量、单图大小、总像素和切片数量均设硬上限，防止解压炸弹与上下文失控。

## 实施步骤

1. 建立视觉请求、图片资产、预处理结果、置信度和降级状态的数据合同。
2. 实现签名校验、方向归一、RGBA/RGB 规范化、元数据清理、大图缩放和有界分块。
3. 实现 Vision Provider 抽象与 Provider 能力路由；远程和本地均使用同一规范消息，不绑定单一模型。
4. 实现六个核心视觉动作、多图比较提示合同和 OCR 后备接口。
5. 接入受权限控制的 API；远程发送要求 network 与图片外发确认，无视觉 Provider 返回明确 `degraded/unsupported`。
6. 增加不确定性、来源、图像哈希、预处理信息和 OCR 后备标记。
7. 增加单图、多图、图表、UI、降级、恶意图片、元数据与凭据隐私测试。
8. 执行完整后端、真实 Ollama 文本回归、Core Eval、前端、Rust、隐私、封包、安装迁移和性能门禁。

## 验收矩阵

| 用例 | 预期 |
|---|---|
| 单图描述 | 真实图片经清理后进入支持视觉的 Provider，返回带置信度与不确定性的结果 |
| 多图差异 | 2–4 张图按输入顺序比较，结果引用稳定 image id |
| 图表读取 | 明确区分可见文字、数值推断和不确定项 |
| UI 截图分析 | 输出观察、可能原因、建议与不确定性，不把推断写成事实 |
| 无视觉模型 | 明确 `unsupported` 或 `degraded`，不得返回伪造描述 |
| OCR 后备 | 只有显式可用的 OCR 引擎才执行并标记 fallback；不可用则 BLOCKED/unsupported |
| 隐私 | 元数据清除、日志不含 base64/图片正文、仓库与历史无密钥 |
| 资源限制 | 超大、超像素、多帧炸弹和非法签名在 Provider 调用前拒绝 |

## 发布规则

只有所有必需门禁完成且无 FAIL/BLOCKED/NOT_RUN，才同步版本源到 `9.6.0`。DeepSeek 付费调用不属于本版本视觉验收范围，状态为 `NOT_APPLICABLE`；24 小时耐久按用户要求为 `NOT_APPLICABLE`；仅本地提交和封包，不推送 GitHub。
