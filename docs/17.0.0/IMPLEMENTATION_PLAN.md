# 司忆 v17.0.0：任务可信执行

基线：`c8835ee` / 16.0.3 Windows 桌面版。目标：每次引导和恢复都可核对到一次具体的任务尝试；不会把上一轮状态显示成当前结果，不会默认把个人记忆交给模型。保留原有权限模式、路径保护、工具确认、凭据和数据目录。

| 验收编号 | 交付 | 可复现验收 |
| --- | --- | --- |
| SIYI17-QUEUE | 运行中引导与会话消息、队列事件一起提交；取消绑定到准确消息，不按正文匹配 | 合成相同文本、写入故障、任务状态竞争、旧记录；用独立 SQLite 读取和 API 响应核对，无半写入或错误删除 |
| SIYI17-ATTEMPT | 刷新和队列接续使用当前尝试的持久事件边界 | 保存第一次中断的结果，启动新尝试并延迟产出；刷新／接续不能显示旧批准项或旧结果，无自动重发 |
| SIYI17-MEMORY | 个人长期记忆只经用户管理入口访问；模型自动检索只用当前项目记忆 | 给个人和两个项目分别写入合成标记，捕获有/无项目任务的实际 Provider 消息；个人 API 保持可用，无访问计数或越界传输 |
| SIYI17-DELIVERY | 冻结源码、便携候选、离线回归和可复核收据 | 版本、文件哈希、回退基线；Python、前端、Rust、固定任务评估、隔离 Windows 冒烟；不把已构建等同于已安装 |

顺序：先为上述边界编写失败复现和测试，再实现、锁定源码、执行本地验证及制品构建。对 SQLite 尝试读回做同机对照，按代表性查询报告中位数与尾部。若使用真实 DeepSeek，只用受控合成数据、低输出上限和零重试的小样本，独立于 CI。真实模型探针不授予模型资格，不涉及用户工作区、聊天或密钥落盘。

范围：Windows PC，不新增依赖或云功能，不更改数据库 Schema；旧客户端和原有审批机制保留。安装器签名、完整真实模型资格、正式发布另受既有门禁约束。
