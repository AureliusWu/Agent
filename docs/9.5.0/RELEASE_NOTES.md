# 司忆 v9.5.0 本地发布说明

- 自动压缩前先保存目标、约束、进度和结构化工作记忆。
- 无工作区与工作区任务均在工具调用完成后写入 checkpoint。
- `now / next / later` 持久队列在安全点按稳定顺序消费运行中引导。
- 新增统一运行状态接口，集中返回进度、Token、上下文、队列和最近 checkpoint。
- 停止保留已完成结果但不可恢复；产品层不再提供暂停，系统中断仍可恢复。
- 历史 `paused` 数据迁移为 `interrupted`，当前 API 和 UI 不再暴露暂停状态。
- 上下文编译继续区分事实、推断、约束、决策、不确定性和证据引用。
