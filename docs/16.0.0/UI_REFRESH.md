# v16 桌面界面调整

本次保持产品版本 `16.0.0`，面向现有 Windows 用户测试基线调整界面；不改变已有验收跳过决定，也不宣称完整正式发行。

## 图标与窗口

- 司忆钥匙改为浅色实底、深青粗线条，适合深浅桌面。SVG、Windows PNG 与多尺寸 ICO 使用同一图形源。
- 自定义顶栏左侧依次为侧边栏开关、新建会话、应用菜单、编辑菜单；右侧保留最小化、最大化/还原、关闭。
- 编辑动作只在用户选择菜单后发生；剪贴板不会在启动时读取。异步粘贴/剪切会检查输入是否已变化。
- 仅为主窗口添加必要的最小化、切换最大化、关闭和拖动权限，不增加文件、Shell 或模型权限。

## 会话输入区

- 新会话空白页依次呈现司忆 LOGO、工作区/模式切换、输入框。已有消息时保留原消息、工具执行、审批、恢复和队列。
- 左右面板默认收起，可从侧边栏开关或应用菜单打开；已有会话与数据不清理。
- 工作区来自用户主动选取的目录和已有会话中的项目，不自动扩大文件访问范围。
- 标准模式默认单 Agent；选择其他已有编排模式后，普通与排队任务均使用该选择，仍受现有权限及预算限制。
- 输入工具依次为添加文件/调用指令、权限、模型、语音、发送。选菜单项不会自动提交消息；忙时的停止、排队和引导继续保留。
- 语音的设备、输入音量、按住说话、快捷键、自动发送、取消和错误提示保留在展开面板内；没有移除录音/转写状态机。

## 检查边界

新增前端检查覆盖空白布局、按钮顺序、窗口与编辑动作、菜单不误提交、编排选择传递，以及输入组件的稳定挂载。继续执行原有安全、桌面组件、语音竞态与构建身份检查。

这些检查不等于真实麦克风、真实模型质量、完整人工工作流或正式安装验收；本次不发送付费模型验证请求。实际本地运行制品的版本、源码与 Build ID 以其嵌入清单和本地激活回执为准，禁止手动修改构建身份。
