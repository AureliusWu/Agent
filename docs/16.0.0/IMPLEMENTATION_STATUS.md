## 本轮收敛的真实缺陷

1. 撤销或补偿过程中，前一步自身重建 inode 会被下一步误判为外部修改；全逆序状态预检及共享预期身份修复，仍对用户外部 drift 拒绝写入。
2. Windows junction/reparse 在最后一次检查后改变可重定向恢复；保留祖先句柄并使用根句柄相对原生改名，四个真实安全探针通过。
3. 批次执行只有前端计划而没有逐步骤崩溃证据；新增 journal、原子所有权、互斥和只读 reconcile，不确定副作用不盲目重放。
4. 大文件备份使用无预算 copy2/copytree；改分块复制，每块核验取消/时限/累计容量并保留失败副本。
5. 本地模型理论上下文被当作运行时事实，小预算被重新抬到2048；改有效观测/显式约束及未知等待，并保留用户的小预算。
6. Eval 缺基线、聚合数字或少跑 pytest 仍可看似绿色；新合同校验完整预定清单、原始逐 case、源码与测量覆盖率。
