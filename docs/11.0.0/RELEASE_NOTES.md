# 司忆 v11.0.0 本地更新说明

- 新增统一 Artifact Engine，支持 Markdown、DOCX、PDF 和 PPTX 的创建与受控编辑。
- 新增 PDF 合并、文本提取和 PDFium 真实渲染，DOCX/PPTX 不可渲染时明确返回不可用。
- 产物写入继续经过工作区边界、权限、快照、审计、文件锁与独立 Verifier。
- 桌面端新增产物下载卡片和安全文件名下载链路。
- 发布环境固定 Python 3.12，增加冻结内容、包体积、SBOM、第三方许可证与独立 LibreOffice 打开验证门禁。

本次仅本地更新，不推送 GitHub。24 小时耐久按用户要求不执行。本文件创建时回归测试尚未开始，最终结论以同目录发布状态与测试矩阵为准。
