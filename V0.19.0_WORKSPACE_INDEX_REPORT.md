# Agent v0.19.0 Workspace Index Report

## Scope

This milestone adds bounded code navigation for the user-selected workspace without introducing a background daemon, database migration, or broader filesystem access.

## Delivered

- Added a rebuildable source-file index for Python, TypeScript, JavaScript, and Rust.
- Added symbol definitions, references and calls, import dependencies, related-test mapping, Git working-tree changes, and parser diagnostics.
- Added `get_repo_map`, `find_symbol`, `find_definition`, `find_references`, `list_module_dependencies`, `find_related_tests`, `get_call_chain`, and `inspect_diagnostics`.
- Added source-state fingerprint invalidation and pruning for dependency, generated, cache, and build directories.
- Added file-count, per-file, total-read, result-count, call-depth, and Git-output limits.
- Routed code-intelligence requests to the new tools through the task-specific model tool selector.

## Verification

- Focused workspace-index, registry, routing, profile, and cache tests: 20 passed.
- Representative scripted Runtime Eval: 4/4 tasks passed.
- Real repository benchmark: 118 source files indexed in approximately 457 ms; cached symbol query completed in approximately 21 ms.
- Full backend suite: 219 passed, 1 environment-specific test skipped; 83.09% coverage.
- Frontend lint, production build, and credential-boundary scan passed.
- Windows desktop Rust tests: 2 passed.

## Boundaries

The index is read-only and remains inside the canonical selected workspace. Python diagnostics use the standard parser. TypeScript, JavaScript, and Rust extraction is conservative navigation metadata, not a substitute for a compiler or language server. Existing permissions, Executor routing, audit, snapshots, verification, and network policy remain authoritative.
