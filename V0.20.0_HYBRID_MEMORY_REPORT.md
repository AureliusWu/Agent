# Agent v0.20.0 Hybrid Memory Report

## Scope

This milestone turns generic workspace memories into classified engineering context while establishing a hard boundary for future personal-companion memory.

## Delivered

- Added `project` and `personal` memory namespaces with a composite workspace/namespace/key identity.
- Added architecture, build command, test command, coding convention, decision, known issue, successful fix, failed approach, and user constraint categories.
- Added a schema v14 migration that preserves memory IDs and content while classifying legacy records.
- Restricted Runtime retrieval and Agent tools to project memory. Personal memory remains user-managed API data and is never injected into engineering context.
- Enforced `deny`, `explicit`, and `allow` memory-write policies at the Runtime/Executor boundary.
- Restricted automatic experience capture to `allow`; independently verified recovery and final failed approaches are stored separately with different confidence.
- Added category-intent retrieval for natural-language requests such as tests, builds, conventions, known issues, and constraints.
- Updated the memory manager with category creation, editing, labels, and filtering.

- Representative scripted Runtime Eval: 4/4 tasks passed with no false completion, permission violation, sandbox violation, or unrelated file modification.
- Frontend lint and production build passed; bundle growth was approximately 0.2 KB.
- Full backend suite: 225 passed, 1 environment-specific test skipped; 83.10% coverage.
- Frontend lint, production build, and credential-boundary scan passed.
- Windows desktop Rust tests: 2 passed.
- A read-only backup of the local Agent database migrated to schema v14 with `quick_check=ok` and the namespace/category columns present.

## Boundaries

Personal memory is not yet a companion-personality feature. It cannot be read, written, or deleted through Agent tools and does not affect model context. All retrieved project memory remains explicitly marked as untrusted reference data and cannot override current instructions, permissions, or tool evidence.
