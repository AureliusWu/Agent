# Agent v0.17.0 Eval and CI Report

## Scope

This milestone separates evaluation into deterministic runtime, autonomous model, and adversarial layers. It adds a compact CI security gate and contract-only interfaces for future companion capabilities without implementing those product features early.

## Delivered

- Eval reports identify their layer and provider type.
- Scripted adversarial tasks cover untrusted prompt injection, destructive approval, workspace traversal, and false completion.
- Evaluation traces include conversation-scoped audit evidence.
- Task contracts can set interaction mode and memory-write policy.
- Six companion contracts cover persona, provider identity, memory conflicts, Conversation Mode, sensitive memory, and voice/text protocol consistency.
- Normal backend tests execute five representative core tasks; all 18 contracts remain validated.
- Real-model CI is manual and samples three tasks. Full suites are reserved for milestones and high-risk changes.

## Verification

- Backend: 208 passed, 1 skipped; 82.60% coverage.
- Adversarial gate: 4/4 passed; zero permission, sandbox, false-completion, or unrelated-file violations.
- Core calibration: 16/18 passed in the first run. Two pytest tasks inherited repository coverage flags because the temporary output was placed under `backend/`; both passed 2/2 after rerunning in the isolated root output directory.
- Core contract: 18 tasks valid. Multi-Agent: 3 valid. Professional Agent: 4 valid. Companion interfaces: 6 valid.

## Release Policy

Routine changes remain local and use focused unit tests plus 3-5 representative Eval tasks. Full evaluation and publishing happen for roadmap milestones, broad runtime or security changes, migrations, release candidates, or explicit user requests.
