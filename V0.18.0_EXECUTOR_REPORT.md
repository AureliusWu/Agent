# Agent v0.18.0 Executor Report

## Scope

This milestone separates the Agent Runtime from the local Windows tool implementation while preserving existing permissions, workspace sandboxing, audit evidence, snapshots, MCP controls, and result contracts.

## Delivered

- Added the stable `Executor` kernel contract with capability, preparation, execution, snapshot, pause, cancel, resume, and cleanup methods.
- Added `LocalWindowsExecutor` as the first implementation.
- Added typed capability, execution-context, and tool-call records.
- Routed Runtime tools through the Executor and retained `ToolProvider` as a backward-compatible facade.
- Canonicalized the selected workspace during task preparation and used that context for every Runtime tool call.
- Raised the kernel contract version from `1.0` to `1.1` and exposed the Executor in the health manifest.
