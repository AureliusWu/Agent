# Agent v1.0.0 Release Candidate Audit

## Scope

Version 1.0 is a stability release for the existing Windows local Agent. It does not add cloud execution, multi-user access, mobile-local execution, arbitrary plugins, or broader filesystem permissions.

## Release-Blocking Acceptance

1. Completed: installed desktop launch uses a test-owned `AGENT_DESKTOP_DATA_DIRECTORY`, creates its database and log, closes normally, and leaves no sidecar process.
2. Completed: uninstall preserves application data; cleanup refuses paths outside the test-owned system temporary directories.
3. Completed: the accepted v0.22 NSIS is installed first, v1 is installed over it, schema 14 data migrates to schema 15, the sentinel survives, and a pre-migration backup is created.
4. Completed: full core, Multi-Agent, and professional suites pass their stable release gates against accepted baselines.

## Verification Summary

- Backend: 231 passed, 1 environment skip, 83.31% coverage.
- Frontend: lint, production build, and credential-boundary scan passed; JavaScript remains 361.54 kB (112.49 kB gzip).
- Windows shell: 4 Rust tests passed.
- Agent Eval: core 18/18, Multi-Agent 3/3, professional Agent 4/4; false completion, permission violation, sandbox violation, and unrelated file modification counts are zero.
- Packaged sidecar cold readiness: 1,543/1,603/1,684 ms; median is 3.1% above the v0.22 same-machine baseline and below the 3,000 ms budget.
- Same-machine NSIS size: 30,209,338 bytes at v0.22 and 30,205,522 bytes at v1.0.0. The frontend bundle is unchanged.
- Local upgrade lifecycle: `previous_version_upgrade`, `schema_migrated`, `migration_backup`, `sidecar_stopped`, `in_place_upgrade_preserved_data`, and `uninstall_preserved_data` all passed.

## Release Decision

`v1.0.0` is ready for remote release-candidate verification. Do not create the final tag until the clean GitHub CI and Windows Release workflow repeat the cross-version acceptance and upload the candidate artifacts.
